# Roadmap

SATARK is an early open-source rebuild. Near-term priorities (subject to change):

## Framework

- [ ] Stabilize the Event / Detection / Finding public API
- [ ] Expand storage backends beyond in-memory / JSONL
- [ ] Optional FastAPI service surface
- [ ] Stronger rule-engine integrations (Sigma/YARA depth)

## Plugins

- [ ] Deepen the insider plugin beyond spike heuristics
- [ ] Replace domain stubs (malware, phishing, web, email, cloud, identity) with research-backed detectors
- [ ] Plugin packaging / discovery conventions

## Knowledge & explainability

- [ ] Versioned knowledge dataset loaders (ATT&CK, CAPEC, CWE, CVE)
- [ ] Richer explanation templates and analyst workflows

## Website & docs

- [ ] Verify and publish historical research references on satark.org
- [ ] Custom domain DNS + TLS for https://satark.org

## Community

- [ ] Issue / PR templates
- [ ] Example notebooks and datasets with clear licensing
