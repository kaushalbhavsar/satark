# SATARK Documentation

**SATARK** (Scalable Automated Technology for Analysis and Ranking of Known Threats) is a modular, plugin-first security analytics framework.

## Vision

Provide a common engine for collecting, normalizing, analyzing, scoring, correlating, and explaining security events—regardless of source—so researchers and enterprises can build reusable detection capabilities across domains.

## Core ideas

1. **Everything is an Event** — vendor formats stop at the plugin boundary.
2. **Explainable risk** — scores always include factors, evidence, confidence, reasoning, and references.
3. **AI as assistant** — detections remain reproducible without LLMs.
4. **Replaceable knowledge** — MITRE ATT&CK, D3FEND, CAPEC, CWE, CVE providers are versioned independently.
