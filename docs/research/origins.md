# Research origins

SATARK originated as security research and is now being rebuilt as an open-source framework.

## Themes carried into the open-source rebuild

- Automated analysis and ranking of known threats
- Insider threat and behavioral analytics
- Transparent / explainable scoring
- Multi-domain detection on a shared architecture
- Malware analysis and web application security techniques
